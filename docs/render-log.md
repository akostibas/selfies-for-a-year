# Render log

Append-only iteration log. One row per non-production render. Newest at the bottom.

Columns (pipe-separated, no nested pipes — escape with `\|`):
- **timestamp** — `YYYY-MM-DD HH:MM` local
- **commit** — short SHA at render time (`git rev-parse --short HEAD`)
- **output** — basename of the rendered MP4 in `/tmp/`
- **song** — short song name; `—` if no music
- **photos** — `kept/source` (e.g. `840/1632`)
- **flags** — key non-default flags (omit `--beat-sync`, `--force`, `--debug-*-overlay`)
- **feedback** — one terse sentence; `?` if not yet reviewed; `✓` if happy as-is

Pacing detail (regions, BPM, tier multipliers) lives in the render's stdout, not here. This is a row-grep target, not a notebook.
